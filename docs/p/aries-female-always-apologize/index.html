常見問題 Q&A

牡羊女先道歉，會不會被對方吃死死？
會，如果妳的道歉永遠沒有附帶說明，對方真的會養成習慣。關鍵不是不要道歉，而是道歉之後要補上妳的真實感受，讓他知道妳是為了關係讓步，不是因為妳理虧。妳可以說「我先開口是因為我在乎，但我希望下次你也主動一點」，把期待講出來，才不會被當成理所當然。平常也要觀察他有沒有在別的地方補償妳，如果完全沒有，那就要認真調整你們的相處模式。
吵架當下牡羊女講話很衝，事後怎麼補救？
牡羊女的衝是情緒反應，不是惡意，所以補救的重點是「分開處理」。先為口氣道歉，但不要為立場道歉，例如「我剛剛太大聲，這點我道歉，但我說的那件事我還是想跟你討論」。把情緒和內容切開，對方比較不會覺得妳在翻舊帳。也可以約定一個手勢或暗號，當妳發現自己快爆走時，比個暫停，先去喝口水，回來再講，這對火象星座超有效。
如果對方就是死不先低頭，怎麼辦？
那妳要判斷他是「不會」還是「不想」。有些人不是不愛，是拉不下臉，這時候妳可以給台階，例如「我知道你也還在氣，但我們不要這樣耗，你先講一句我就接」。但如果長期都是妳在撐、他完全沒有要修補的意思，那這就不是星座問題，是關係裡的權力不平衡。妳可以設一個觀察期，例如一兩個月，看他有沒有因為妳的溝通而改變，沒有改變就要認真思考這段關係值不值得妳一直先低頭。
