常見問題 Q&A

金牛男說喜歡但不交往，是不是代表他其實沒那麼喜歡我？
不一定，金牛男的喜歡常常是真的，但他的喜歡跟承諾是分開的。他可能很享受跟你相處的舒適感，卻還沒準備好改變生活結構。你要觀察的是他有沒有在行動上靠近，例如主動安排見面、願意為你調整時間、把你介紹給朋友，如果只有嘴巴說喜歡卻沒有任何推進動作，那這份喜歡對你來說就不夠用，你要自己設停損。

逼得太急確實會讓金牛男壓力爆表然後退縮，因為固定宮最怕被逼迫改變。但你可以用溫和但清楚的方式表達需求，例如告訴他你需要一個方向感，而不是要他立刻簽合約。給他時間思考，同時讓他知道你不會無限等待，這種有界線的溫柔反而會讓他認真面對，而不是用逃避來處理。
金牛男不交往但又會吃醋、會管我，這是什麼心態？
這是典型的金牛男佔有慾，他把你當成自己習慣擁有的存在，但不想付出交往的責任。他吃醋是因為覺得你是他的舒適圈，不是因為他準備好承諾。你要溫和地戳破這件事，可以說：「你會在意我跟別人互動，但我們又沒交往，這樣我會有點混亂，你要不要想清楚我們到底是什麼關係？」讓他面對自己的矛盾。
