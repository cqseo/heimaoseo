深度解析

具體建議

常見問題 Q&A

巨蟹女常主動找我聊天，是不是代表她喜歡我？
不一定，巨蟹女本來就習慣用聊天維持關係，關鍵要看聊的內容深度。如果她只聊吃喝玩樂、抱怨工作，那可能只是把你當抒發對象；但如果她開始聊家裡的狀況、以前的感情經驗、自己脆弱的一面，甚至會問你對未來的想法，那就代表她把你放進比較內心的位置了。你可以觀察她是不是只對你這樣，還是對很多人都一樣，這是最準的判斷方式。
我已經告白了，巨蟹女說要再想想，我該等嗎？
可以等，但要有期限。巨蟹女說再想想通常不是拒絕，是她真的在評估安全感，她需要時間確認你是不是穩定的人。你可以給她兩到三週的空間，這段時間保持正常互動但不要一直追問答案，也不要刻意冷淡。如果超過一個月她還是沒有正面回應，而且互動明顯變少，那代表她其實已經用行動回答了，你就不要再耗下去了。
怎麼分辨巨蟹女是真心還是只是把我當備胎？
看三件事：第一，她會不會主動約你，不是只有你約她才出現；第二，她願不願意讓你進入她的生活圈，比如介紹朋友給你認識、讓你知道她週末都在幹嘛；第三，她會不會在你面前展現不開心的樣子。如果這三件事她都做不到，只有你需要的時候她剛好出現，那備胎的成分就很高。真心喜歡你的巨蟹女，會慢慢把你拉進她的世界，而不是只在你主動的時候才回應。
