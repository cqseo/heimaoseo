摩羯男說喜歡我卻不交往，是不是代表他其實沒那麼喜歡？
不一定，摩羯男的喜歡跟交往是分開評估的，他可能真的很喜歡你，但覺得現階段條件不允許，例如事業不穩、經濟壓力大、或還沒從上一段感情走出來。你要看的是他有沒有在行動上持續靠近你，如果他有主動關心、記得你的需求，那他的喜歡是有重量的，只是被現實考量卡住了，這時候與其逼他表態，不如陪他一起把現實條件慢慢補起來。
