深度解析

抽到月老靈籤第73籤，說真的，這支籤擺在「分手後他會回來嗎」這個問題前面，第一個要跟你講的是：它不是一支「他馬上就會衝回來找你」的籤，但它也絕對不是一支「從此斷乾淨」的籤。第73籤的籤象很有意思，它比較像是一個人在驛站裡面等車、等消息、等一個東風的狀態，籤意裡面藏著「時機未到、情分未斷、但主動權不在你身上」這三層訊息。也就是說，你們之間的那條線其實還沒有完全斷掉，他心裡對你不是沒有感覺，甚至夜深人靜的時候他會想起你，可是現階段的他卡在自己的狀態裡，可能是面子拉不下來、可能是還沒想清楚自己要什麼、也可能是他覺得先冷靜一陣子對彼此都好。所以這支籤在講的不是「他會不會回來」的是非題，而是「他回來之前，這段時間你要怎麼過」的申論題。很多姊妹抽到這支籤會很急，一直問月老「那到底什麼時候」，但這支籤的節奏本來就偏慢，它要你看見的是：你們分開的這件事，其實幫你照出了一個很真實的東西，就是他現在的處理感情的方式，跟你要的安全感之間，是有落差的。與其說他在等你，不如說老天爺在等你把自己穩下來。你要理解的是，第73籤的「等」不是空等，是有質感的等，是那種把自己照顧好、把生活過回來、讓他回頭看你的時候會愣一下的等。如果你在這段時間把自己搞得亂七八糟、每天盯手機、發限動給他看、找人去打聽他的消息，那這支籤的能量就會被你自己消耗掉，本來會回來的緣分也會被你嚇跑。所以籤意真正的核心是：情分還在，但現在是「靜候」的階段，你要當那個把自己過得發光的人，而不是當那個守在原地哭的人。

具體建議

既然知道是「靜候」的階段，那實際要怎麼做？第一個建議是給自己設一個「不主動聯絡的觀察期」，我建議抓四十五天到六十天，這段時間你完全不要主動傳訊息、不要按他讚、不要在他常出現的地方晃，目的是讓他的生活裡真的出現你的空缺，人才會開始想念。第二個建議是準備一句「重啟對話的安全牌」，等觀察期過了、或者他先敲你了，你可以用很輕的語氣回：「最近整理東西看到你之前推薦的那間店，想說你最近還好嗎？」這種話沒有壓力、沒有質問、也沒有把復合兩個字搬上檯面，但會讓他覺得跟你講話是舒服的。第三個建議是趁這段時間做一件「讓自己升級」的具體事，比如報名一個你一直想學的課、把身材練回來、或者把房間重新布置，這不是為了他，是為了讓你在等待的過程裡有主控感，因為當你每天都有前進的感覺，你就不會把全部的情緒押在他回不回來這件事情上。第四個建議是安排「情緒出口」，找一個可以講話的閨蜜，固定每周約一次，把想講的話講出來，但講完就收，不要讓自己每天無限循環地分析他。第五個建議是幫自己訂一個「停損點」，比如三個月後如果他完全沒有動靜，你就要開始把重心轉回自己身上，因為這支籤雖然說情分未斷，但緣分這種事情不是單方面撐著就會成，你要給自己一個期限，才不會等到最後連自己都弄丟了。時機判斷上，如果他在這段期間有主動丟訊息、問你近況、或者透過共同朋友打聽你，那都是好的訊號，代表他心裡那條線還在跳動；但如果完全無聲無息，你也要有勇氣承認，有些人回來是緣分，有些人沒回來是老天爺在幫你擋掉一個不適合的人。

💡 實用小提醒

  • 觀察期先抓四十五天，期間不主動聯絡、不看對方社群，讓空缺自然發酵。
  • 重啟對話用輕語氣開場，例如提到共同回憶的小事，不要一開口就問復合。
  • 幫自己設三個月停損點，時間到沒動靜就把重心收回自己身上。

常見問題 Q&A

如果他已經封鎖我，這支籤還有希望嗎？
封鎖這種事情通常是情緒當下的動作，不代表永久，第73籤的訊息是情分未斷，所以不用立刻絕望。但你要做的是先完全不動作至少一個月，讓他的情緒降溫，期間不要用其他帳號去看他、也不要託朋友傳話，因為那只會讓他覺得被糾纏。一個月後如果共同朋友有自然的場合可以碰到，再若無其事地打個招呼就好，重點是讓他看到你過得很好，而不是急著解釋或復合。
他回來聯絡了，我應該馬上答應復合嗎？
不要馬上答應，這是第73籤給你的提醒。他回來聯絡只代表他想起你，不代表你們原本的問題解決了，所以你要先觀察他這次回來的態度是認真還是無聊。建議先當朋友聊兩到三周，看他有沒有主動提到之前分開的原因、有沒有想調整的地方，如果他都避而不談，那復合之後大概率會再吵一次。你可以溫和地說：我很開心你找我，但我想我們都需要想清楚之前的事，不急。這樣既沒有把人推走，也守住自己的底線。
要怎麼判斷他是真的想復合還是只是寂寞？
看三件事：第一，他有沒有主動談到未來，比如約下個月的活動、問你最近的計畫，這代表他想把你放進生活裡；第二，他有沒有對之前分手的原因表態，願意講開的代表他有在想；第三，他找你的時間是不是都在深夜或無聊的時候，如果只有半夜才想到你，那大概率是寂寞不是認真。你可以用輕鬆的語氣試探：你最近怎麼會想到找我？聽他的回答就知道他是把你當選項還是當重要的人。
