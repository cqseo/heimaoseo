常見問題 Q&A

她說要冷靜，我到底該不該主動密她？
可以密，但頻率要低、內容要輕。建議兩三天一次，分享生活小事就好，不要問「妳想我了嗎」或「妳考慮得怎樣」。你可以傳一則好笑的影片說「看到這個想到妳」，讓她知道你還在，但沒有逼她。如果她已讀不回，也不要追問，給她空間，她準備好了自然會回。

水瓶女通常需要三到七天消化情緒，超過兩週就有點久了。你可以觀察她有沒有還在做平常會做的事，比如發限動、按你讚，如果有，代表她只是需要空間，不是要斷聯。如果她完全消失超過兩週又封鎖你，那可能真的要坐下來談清楚，但不要自己腦補，直接約她聊比較準。
她冷靜完回來，我該怎麼開口比較好？
不要一開口就翻舊帳，先謝謝她願意回來談。你可以說「謝謝妳願意跟我說這些，我這幾天也有想一下」。然後先聽她講，不要急著反駁，等她講完你再說你的感受。重點是讓她覺得跟你溝通是安全的，不是一講就被檢討，這樣她才會願意繼續跟你走下去。
