深度解析

親愛的，先抱一個，我知道你現在心裡一定很阿雜，因為射手座男生就是有一種本領，嘴巴上說得天花亂墜，什麼「我真的很愛你」、「你是我遇過最特別的人」，講得你心花怒放，結果轉頭就跑去跟朋友打球、打電動，訊息已讀不回，約會也常常臨時取消，讓你忍不住懷疑自己是不是被當成塑膠做的。其實你要先搞清楚一件事，射手座男生的「愛」跟一般人的「愛」定義不太一樣，他們是火象星座，由木星守護，天生就是一個追求自由、熱愛探索、活在當下的人，對他們來說，說出「我愛你」的當下，那個情緒是真的，他沒有騙你，只是他的行動力往往跟不上他的嘴巴，因為他很容易被新鮮事物吸引走注意力，加上他不太擅長處理那種需要細膩經營、反覆確認的親密關係，所以他會用「我以為你知道我愛你」來合理化自己的鬆散。這不是他不愛你，而是他的愛比較像一陣風，來的快去的也快，你需要的是幫他把這陣風變成穩定的氣流。另外，射手男很怕被綁住、被要求、被情緒勒索，當你越是用「你都不陪我」、「你說愛我為什麼做不到」這種方式去質問他，他反而會覺得壓力很大，下意識就想逃，因為他會覺得你在限制他的自由，這是他最無法忍受的事情。所以你要看懂的是，他的行動不一致，很多時候不是故意要讓你難受，而是他根本沒意識到問題的嚴重性，他覺得「我們之間又沒吵架，感情很好啊」，完全沒發現你已經在心裡小劇場演了八百集。還有一個很關鍵的點，射手男是視覺跟感覺的動物，他喜歡輕鬆、有趣、沒有壓力的相處模式，如果你們的互動變成一直在檢討他、一直在要承諾，他會覺得這段關係變得很沈重，然後就開始找藉口閃躲。所以與其說他不愛你，不如說他不知道怎麼用你期望的方式去愛你，他需要被引導，而不是被責備。你要做的是讓他覺得跟你在一起是開心的、是自由的，同時又慢慢建立起他對這段關係的責任感，這需要一點策略跟耐心，但絕對不是要你委屈自己，而是用對方法讓他心甘情願留下來。

具體建議

好，既然我們已經看懂射手男的心理了，接下來給你幾個具體可以操作的做法，讓你不用再自己一個人內耗。第一個建議是「用輕鬆的方式把需求講清楚，不要用質問的語氣」，比如說你可以在氣氛好的時候跟他說：「欸，我發現你嘴巴很會講愛我，但行動好像常常跑去打電動耶，這樣我會有點小寂寞，下次你要打之前先傳個貼圖給我好不好，讓我感覺你有想到我。」這種講法沒有指責，反而帶點撒嬌，射手男很吃這一套，因為他覺得你在跟他溝通而不是在管他，他比較願意配合。第二個建議是「把你們的約會變成他會期待的事情」，射手男喜歡新鮮感，所以你不要每次都問「週末要不要見面」，你可以直接丟一個有趣的提案，比如：「我發現一家新開的居酒屋，聽說串燒很強，這禮拜五晚上要不要一起去踩點？」給他一個具體的、有畫面的邀約，他會覺得跟你出門很好玩，自然就會把時間留給你，這比你一直問他「你什麼時候有空」有效一百倍。第三個建議是「設立一個溫柔但清楚的界線」，你可以跟他說：「我知道你很需要自己的空間，我也覺得那樣很好，可是如果我們約好了，你臨時要改，我希望你可以提前跟我說，不要讓我傻傻等，這樣我會覺得不被尊重。」把重點放在「提前告知」而不是「不准取消」，射手男會覺得你講理，反而更願意做到。第四個建議是「用行動讓他感受到你的重要性，而不是用嘴巴要」，射手男其實很聰明，他會觀察你是不是一個有自己生活、有魅力的人，所以你不要把全部重心放在他身上，你去學個新東西、跟朋友出去玩、把自己過得很精彩，當他看到你沒有他也活得很好，他反而會主動靠近你，因為射手男天生就喜歡追逐的感覺，你越是有自己的光，他越會想黏過來。第五個建議是「偶爾給他一點小任務，讓他為你付出」，比如你可以說：「我最近想買一本書，可是好懶得去逛，你幫我挑一本你覺得我會喜歡的，好不好？」讓他為你做一點小事，他會產生一種「我對這個女生有責任」的感覺，這比你要他每天報備有用多了。記住，對付射手男，與其拉緊繩子，不如把草放遠一點，讓他自己跑過來吃。

常見問題 Q&A

射手男說愛我但都不主動約我，是不是沒那麼喜歡我？
不一定喔，射手男主動約人的頻率本來就比較低，因為他習慣想到什麼做什麼，比較少事先規劃，這不代表他不喜歡你，而是他的節奏比較隨性。你可以試著主動丟出有趣的邀約，觀察他願不願意配合，如果他每次都說好而且很開心，那就是有喜歡，只是他懶得當發起的人。但如果他連你約了都一直推託，那就要注意了。
射手男很愛跟異性朋友出去玩，我該怎麼跟他溝通？
不要用禁止或懷疑的語氣，射手男最討厭被管，你可以這樣說：「我知道你朋友很多，我也覺得這樣很好，可是有時候我會沒安全感，不是不信你，是我自己會想太多，你可以偶爾主動跟我說你跟誰出去、大概幾點回來嗎？讓我安心一下。」把重點放在你的感受而不是他的行為，他比較聽得進去，也比較願意主動報備。
要怎麼讓射手男主動一點，不要每次都是我找他？
射手男是獵人性格，你越追他越跑，所以你要反過來，把自己的生活過得精彩，偶爾在社群發一些有趣的動態，讓他看到你沒有他也很開心，他就會產生好奇跟一點點危機感。另外你可以偶爾已讀他慢一點，不要每次都秒回，讓他感受到你不是隨時都在等他，他就會開始主動找你，這招對射手男特別有效。
