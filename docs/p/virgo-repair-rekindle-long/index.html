深度解析

常見問題 Q&A

長期感情要重新點燃熱情，處女座最常犯的錯是什麼？
最常犯的錯就是「只做不說」跟「等對方先改變」。處女座很會默默付出，但對方不一定感受得到，久了兩個人都覺得委屈。另一個錯是把約會變成任務清單，讓相處充滿壓力。建議你從今天開始練習把付出說出口，並且主動創造沒有目的的相處時光，熱情才有空間重新長出來，不要一直等對方先動作。
