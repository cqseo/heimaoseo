常見問題 Q&A

牡羊座跟處女座吵架的時候，誰該先低頭？
不用爭誰先低頭，重點是設一個「暫停規則」。牡羊情緒來得快去得也快，處女則是會在心裡反覆咀嚼。建議吵到氣氛變僵時，牡羊先說「我需要十分鐘冷靜，等等回來講」，處女先說「好，但我們九點要坐下來講完」。牡羊先離開現場不是逃避，是避免話越說越重；處女願意設定回頭時間，是給牡羊一個明確的訊號。兩個人都不必覺得自己輸了，先暫停的人其實是比較成熟的那一個。

會，但可以談。牡羊的慾望比較直接、比較即時，處女則需要放鬆、需要氛圍、需要心理上先安心。建議不要用「次數」來談，改用「品質跟感受」來談。牡羊可以主動問「你什麼時候比較放鬆」，處女可以明確說「我需要先好好吃頓飯、聊聊天」。兩個人可以約一個「不一定要做什麼的親密時間」，先從擁抱、按摩開始，壓力拿掉之後，頻率反而會自然靠近。重點是不要讓其中一方覺得自己一直在配合或一直在被拒絕。
