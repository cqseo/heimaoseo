常見問題 Q&A

天蠍座分手後完全斷聯，是不是代表沒機會了？
不一定，天蠍座的斷聯常常是「自我保護」而不是「徹底放棄」。他們需要時間整理情緒，也在觀察你會不會亂炸。你可以先安靜七到十天，之後用一個跟感情無關、但跟他生活有關的小訊息開場，例如他之前提過的展覽或工作狀況。重點是不要問「你是不是不愛我了」，而是讓他感覺你懂他的節奏。如果他已讀不回但沒封鎖，通常還有戲，持續穩定但不騷擾的互動，比狂傳長文有用。
天蠍座復合後會不會翻舊帳？要怎麼應對？
會，而且會翻得很細，因為他們要確認你是真的改變，不是暫時裝乖。應對方式是「不辯解、不崩潰、給具體證據」。例如他提起你以前常消失，你不要說「我哪有」，你可以說「對，那次我沒說就消失，難怪你會不安，我現在出門前會先講一聲」。天蠍座要的是你承認他的感受，不是要你認罪。你越坦誠，他翻舊帳的頻率會越低，因為他發現你真的有在記。
如果天蠍座身邊已經有曖昧對象，我還有機會嗎？
有機會，但難度提高，因為天蠍座在曖昧期會刻意拉距離來測試自己的心。你不要去跟他比較，也不要打聽那個人的事，那只會讓他覺得你在監控。你可以把重點放回你們之間「未完成的情感連結」，用回憶裡的具體小事觸動他，例如「我今天經過那家我們常吃的麵店，老闆還問你怎麼沒來」。語氣要輕鬆，不要酸。同時你要讓自己過得好，天蠍座會被「穩定又有自己生活」的人重新吸引，你越焦慮他越跑。
