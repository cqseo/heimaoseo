常見問題 Q&A

地母廟的月老紅線通常要連續三個聖筊才代表月老同意給你，如果一直擲不到，先不要急著走，停下來重新檢查你剛剛講的條件是不是太模糊或太貪心，比如同時想要高富帥又想要溫柔體貼，月老會覺得你在開玩笑。建議把條件縮到三個最核心的，像是價值觀相近、願意溝通、沒有藕斷絲連的前任，再重新擲筊，通常就會過了。如果真的擲了十幾次都沒有，代表時機還沒到，可以跟月老說「那我下次再來」，回去把自己狀態調整好，過一兩個月再來，不要硬求。

已經有曖昧對象，可以去地母廟求紅線嗎？會不會把緣分求歪？
可以去，但心態要對，不要抱著「求月老幫我把他綁住」的執念，因為月老牽的是正緣，不是幫你控制別人。你可以跟月老說「我現在有一個曖昧對象，請幫我看清楚他是不是適合我的人，如果是，請幫我們順利發展，如果不是，請幫我放下」，這樣許願會比較健康。另外求紅線當天不要跟曖昧對象一起去，自己一個人去，把焦點放在自己身上，回來之後也觀察對方有沒有更主動、更願意表態，如果沒有，就代表月老在幫你篩選，不要硬撐。
