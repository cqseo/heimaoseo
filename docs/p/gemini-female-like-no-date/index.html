常見問題 Q&A

她說喜歡我卻不想交往，是不是在養工具人？

我該不該直接跟她斷聯逼她表態？
對雙子女來說斷聯風險很高，她不會被逼出真心，只會覺得你情緒化然後順勢淡掉。比較好的做法是降低頻率而不是消失，比如從每天聊變成兩三天聊一次，訊息回得慢一點但內容依然有趣，讓她感覺到你不一樣了，這種若有似無的距離感才會讓雙子女開始在意。
雙子女說不想交往，之後還有機會改變嗎？
有，但關鍵不在說服而在體驗。雙子女的決定很少是被講道理講動的，而是被某個相處瞬間打動。你要做的是持續創造輕鬆愉快的相處，讓她在某個時刻自己冒出「好像跟他在一起也不錯」的念頭。切記不要一直提交往兩個字，那只會讓她反覆啟動防禦機制。
