深度解析

親愛的，抽到塔羅正義逆位，然後問「對方有沒有在想我」，其實你心裡大概已經有個底了，只是需要有人幫你把那個感覺說清楚。正義牌正位的時候，代表的是天秤、平衡、理性判斷，還有因果關係，也就是說，當正位出現，對方對你的想法是經過思考的、是有在衡量這段關係的輕重，甚至他會很清楚地知道誰付出多誰付出少。但逆位的時候就不一樣了，正義逆位代表的是失衡、逃避面對、該做的決定拖著不做，還有一種很明顯的「自我欺騙」。所以針對「他有沒有在想我」這個問題，逆位給的答案不是「完全沒想」，而是「他有想，但他想的方式很不健康，而且他不敢承認」。他可能在腦中反覆播放你們之間的一些片段，但他會用一種很扭曲的角度去解讀，比如把錯都推給你，或者說服自己「我們本來就不適合」，用這種方式讓自己好過一點。正義逆位也常常代表「雙標」，他對你的要求是一套，對自己又是另一套標準，所以他想的內容可能不是溫柔的思念，而是充滿比較、計較、還有不甘心。更關鍵的是，正義逆位有一種「卡住」的能量，他明明知道有些事情該處理、有些話該說清楚，但他選擇裝死，因為一旦面對了，他就得承認自己也有責任。所以親愛的，你不要再幫他找藉口了，他不是沒空想，他是想了卻不想負責。這張牌也在提醒你，不要因為他偶爾的已讀、偶爾的關心就覺得「他應該還在乎我」，因為正義逆位的人很擅長用最小的力氣維持一個「我沒有完全消失」的假象，好讓自己不會有罪惡感。你要看清楚的是，他現在的思考模式是失衡的，他沒有在一個可以好好處理感情的狀態裡，所以就算他想你，那份想念也不會變成實際的行動或真誠的溝通，反而可能讓你更內耗。

具體建議

好，那既然知道他是這種「有想但不敢面對」的狀態，你接下來可以怎麼做？第一個建議，先停止「等他給答案」這個動作，因為正義逆位的人最會拖，你越等他越裝死。你可以做一個很具體的動作：把你們最後一次對話從頭看一遍，然後拿一張紙，左邊寫「他實際做了什麼」，右邊寫「我自己腦補了什麼」，你會發現右邊那欄通常比較長，這個練習可以幫你把重心拉回自己身上。第二個建議，如果你真的想試探他有沒有在想你，不要用「你是不是都沒在想我」這種質問句，你可以用一個很中性的訊息，比如「我前幾天整理照片看到我們去某某地方那張，突然覺得那時候很好笑」，這種話沒有壓力，但會勾起他的回憶，而且你講完就放著，不要追問，觀察他回覆的速度和內容深度，如果他又開始已讀很久或回得很表面，那就是正義逆位的標準反應，你心裡就有數了。第三個建議，設定一個「停損點」給自己，比如再給他兩週，這兩週內你不主動提感情的事，只做你自己該做的事，兩週後如果情況完全沒變，你就把這件事結案，不要讓自己一直處在「他到底想不想」的迴圈裡。第四個建議，如果你們還有共同朋友，不要透過朋友去問「他有沒有提到我」，因為正義逆位的人很會在外面塑造一種「我很好啊沒差」的形象，你聽到的可能都不是真的，反而讓自己更混亂。第五個建議，把正義牌的能量拿回來自己身上，正義講的是公平，你現在要對自己公平一點，你可以每天睡前問自己「我今天有沒有為自己的快樂做一件事」，如果沒有，隔天馬上補做，當你把自己的生活過得平衡，你就不會那麼需要從他的反應裡找安全感，而且很妙的是，當你不再繞著他轉，正義逆位那種「卡住」的能量反而會鬆動，他可能會因為感受到你不再被動等待而開始有點反應，但那時候你搞不好已經沒那麼在意了，這才是真正的贏。

常見問題 Q&A

正義逆位是不是代表他完全沒在想我？
不是完全沒想，而是他想的方式很封閉也很矛盾。他可能反覆想你們之間的事，但會用計較、比較或自我保護的角度去解讀，所以就算有想，也不會轉化成真誠的行動。你要看的不是他有沒有想，而是他有沒有想要好好處理，逆位通常表示他選擇逃避，所以別把他的想念當成還有希望的證據。
我要主動問他「你有沒有在想我」嗎？
不建議直接問，因為正義逆位的人被問到這種問題會立刻啟動防衛機制，他可能回「有啊」但語氣很敷衍，或者反過來挑你毛病。你可以改用分享回憶的方式丟球，例如提到某個共同經歷，然後觀察他回覆的溫度和長度。如果他只回貼圖或嗯嗯，你就知道他的狀態還沒準備好面對，你也不用再逼問。
正義逆位多久會好轉？我該等嗎？
沒有固定時間，但你可以給自己一個明確的觀察期，比如兩到三週。這段時間你不要主動提感情，只維持正常互動，看他有沒有主動推進或願意講開。如果觀察期過了還是一樣閃躲，那就不是時間問題，是他根本不想面對。等待本身沒有錯，但要有停損點，不要讓等待變成無限期的自我消耗。
