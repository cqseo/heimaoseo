常見問題 Q&A

他說不知道，是不是代表他其實不喜歡我，只是不想傷害我？
不一定喔。很多男生說不知道，是真的還沒整理好自己的感覺，尤其如果他跟妳相處的時間還不夠長，他可能還在觀察。妳可以看他後續的行動，如果他還是一直主動找妳、約妳出去，那他的不知道比較像是「還沒想清楚但不想失去妳」。但如果他說完不知道之後就消失、訊息回很慢，那妳心裡就有底了。重點是不要用一句話定生死，給彼此一點時間，但也要設停損點。

先別慌，尷尬是正常的。妳可以主動用輕鬆的語氣化解，比如說：「哎唷那天問那個問題我自己也覺得太直接了，你不要放在心上啦，我們就順其自然就好。」然後趕快轉移話題，聊一些你們平常會聊的、好玩的事情。雙魚女生很擅長營造舒服的氛圍，妳就把這個能力拿出來用，讓他知道妳沒有要逼他，相處起來還是很自在。過幾天再約他做一些簡單的活動，用行動證明你們之間沒有因為那個問題變調。
我要怎麼判斷他是真的在猶豫，還是在吊我胃口？
觀察他有沒有「主動性」跟「持續性」。如果他在妳問完之後，還是會主動傳訊息、約妳、關心妳的生活，那他的猶豫可能是真的在思考你們的關係。但如果他只有在他無聊的時候才找妳，或者妳不主動他就完全不動，那妳就要小心了。另外，妳可以注意他有沒有把妳介紹給他的朋友，或者願不願意跟妳聊比較內心的東西，這些都是判斷他認不認真的指標。雙魚女生很容易幫對方找藉口，所以妳要練習看事實。
