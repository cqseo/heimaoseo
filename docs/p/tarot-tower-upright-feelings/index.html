深度解析

常見問題 Q&A

高塔正位是不是代表他已經不愛我了？
不是這樣看的。高塔正位代表他原本對這段關係的認知被打破了，可能是他發現自己比想像中更在乎，也可能是他發現你們的關係不能再停留在模糊地帶。這張牌的重點是「舊的框架倒了」，不是「感情沒了」。所以與其問他愛不愛，不如觀察他有沒有在廢墟裡試著靠近妳，那才是真正的心意指標。
他最近態度很反覆，一下熱一下冷，我該主動問清楚嗎？
不建議直接逼問，因為高塔正位的人自己都還在整理思緒，妳一問他反而會築牆。比較好的做法是用低壓的方式丟一個小邀約或小關心，例如「今天經過那間店想到你」，然後看他怎麼接。如果他願意多聊兩句，就順著聊；如果他簡短回應，妳就點到為止。給他空間，但讓他知道門是開著的，這比逼問有效得多。
我要怎麼判斷他是在整理還是在疏遠？
看兩個指標：第一，他有沒有「主動但笨拙」的接觸，比如突然傳一個奇怪的貼文、問一個不重要的問題，這通常是高塔正位的人想靠近又不知道怎麼開口的訊號。第二，看他在妳面前有沒有比較真實，比如講話變直接、願意透露一點私事。如果完全沒有主動、也沒有真實感，那可能真的是在拉開距離，妳就要把重心收回來，先過好自己的生活。
