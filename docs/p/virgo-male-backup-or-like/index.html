常見問題 Q&A

處女男主動報備行程，代表他喜歡我嗎？
不一定，要看報備的「質」而不是「量」。處女男本來就有交代事情的習慣，但如果他的報備開始包含「細節」跟「感受」，比如不只說「我在跟朋友吃飯」，而是說「今天跟大學同學吃飯，他最近換工作超焦慮的，害我也跟著想很多」，這種把內心狀態也交給你的報備，才是喜歡的訊號。單純的行程報備有時候只是他的禮貌慣性，你要看的是他有沒有把你放進他的情緒圈子裡。
