常見問題 Q&A

寶劍國王出現是不是代表他已經不愛我了？
不是不愛，是他把愛收起來用理性在檢查。寶劍國王不是無情，他是怕再痛一次，所以先啟動保護機制。他心裡其實還在評估，只是他不會用眼淚或甜言蜜語表達。你要看的是他有沒有在觀察你、有沒有回你訊息、有沒有問你近況，這些都是他還在意的訊號。真正放下的人是不會花力氣去分析的，他會直接消失。
逆位寶劍國王在復合牌陣裡是不是更糟？
逆位要分兩種看。一種是他變得太苛刻、講話帶刺，另一種是他理智斷線、情緒失控。但不論哪一種，都代表他其實內在有壓抑的東西沒有處理好。這時候你不要硬碰硬，也不要急著安撫，先拉開一點距離，讓他自己冷靜。你可以傳一句「我知道你現在很煩，我先不吵你，等你想談再跟我說」，這樣反而會讓他覺得你成熟，逆位的力量就會慢慢轉正。
我要怎麼做才能讓寶劍國王對我改觀？
關鍵字是「具體」。他不會因為你哭得多傷心就軟化，但會因為你講出一個清楚的做法而動搖。比如你告訴他「以後我們有意見不合，我會先講我的需求，不會直接消失」，然後在接下來幾次互動裡真的做到。寶劍國王是看行為的，你只要連續三次讓他看到你說到做到，他心裡那本帳就會開始改寫。記得，不要只說一次，要讓他有觀察到的機會。
