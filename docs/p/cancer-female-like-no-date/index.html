常見問題 Q&A

巨蟹女說喜歡我但不想交往，是不是在養工具人？

可以，但要有節制，不要把所有好一次給完。巨蟹女會習慣被照顧，你給太多太快，她反而覺得理所當然。建議你把付出變成有節奏的，例如一週主動約一次、日常問候固定但不黏，同時保留自己的生活圈，讓她知道你是有重心的人，這樣她反而會更想靠近你。
要怎麼問巨蟹女才不會讓她覺得被逼？
避開「我們到底算什麼」這種逼定義的問法，改用感受式開場，例如「我最近在想我們的事，我對你是認真的，但我不想給你壓力，你願意跟我說你現在的想法嗎？」語氣放軟、眼神溫和，說完不要急著要答案，給她幾天消化，巨蟹女需要時間整理情緒，你越從容她越敢說真話。
