常見問題 Q&A

摩羯男說完分手後還每天看我限動，是什麼意思？
這代表他根本沒放下，只是在用最低成本的方式確認你的狀態。摩羯男分手後通常不會大動作挽回，但他會默默追蹤你的生活，看你過得好不好、有沒有新對象。你可以維持正常發文頻率，偶爾發一點生活感強但不刻意的內容，例如運動、跟朋友吃飯，讓他感覺你穩定又獨立，這比直接密他更有機會讓他主動開口。
我要主動密他嗎，還是等他來找我？
建議先等七到十天，讓雙方情緒沉澱。如果期間他完全沒動靜，你可以用一件具體小事破冰，例如傳一個他之前提過的東西說：剛好看到這個，想到你之前說想要。重點是語氣輕鬆、不談感情、不求回應，摩羯男對這種沒有壓力的訊息接受度很高，也比較容易順著台階回來。
摩羯男交往前說分手，是不是代表他其實沒那麼喜歡我？
不一定，很多時候剛好相反。摩羯男對沒感覺的人根本不會走到需要喊分手的地步，他會直接淡出。會特別提出來，代表他已經在心裡把這段關係當成一回事，只是他評估後覺得時機或條件不對。你要看的是他有沒有持續關注你、有沒有保留聯絡管道，這些細節比那句話本身更誠實。
