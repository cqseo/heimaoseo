常見問題 Q&A

水瓶男主動密我但約不出來，是什麼意思？
這代表他對你有好奇心，但還沒準備好把關係放進現實生活裡。水瓶男很常在線上聊得很開心，因為文字對他來說是低壓力的交流，但約會牽涉到真實互動跟時間承諾，他會猶豫。你可以先從群體活動或超短暫的約會開始，比如喝一杯咖啡三十分鐘就好，降低他的壓力感，讓他發現跟你見面其實很輕鬆，之後再慢慢拉長相處時間。
追水瓶男是不是不能太主動？
不是不能主動，是不能「壓迫式主動」。水瓶男討厭被催被逼被情緒勒索，但他其實喜歡有想法、敢表達的女生。關鍵在於你主動的內容要是「分享」而不是「索取」，例如分享一個有趣的資訊、提出一個好玩的邀約，而不是一直問他在幹嘛、為什麼不回。把主動權用在創造有趣的互動上，而不是用在確認關係上，他就會覺得跟你相處很舒服。
三個月沒進展，要怎麼試探他到底有沒有喜歡我？
不要用試探，用「自然揭露」比較準。你可以在聊天時不經意提到「最近有人在追我，但我還在觀察」，然後看他的反應，如果他開始問細節、語氣變酸或突然變積極，代表他其實在意。另一個方法是減少主動聯絡一週，觀察他會不會主動找你，水瓶男如果真的有感覺，在你消失的時候他會明顯感受到不對勁，這時候他的行動會比任何試探都誠實。
