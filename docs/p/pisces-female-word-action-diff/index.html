深度解析

常見問題 Q&A

他說愛我但行動不一致，是不是代表他其實沒那麼喜歡我？
不一定，但這絕對是一個警訊。有些男生是「語言型戀人」，很會說但行動力差，可能是個性懶散或習慣用嘴巴談戀愛；但也有可能是他沒那麼投入，只是享受被妳喜歡的感覺。妳可以觀察他對「重要的事」的態度，比如妳生病時他會不會主動關心、妳需要帮忙時他會不會出現，如果連這些基本行動都沒有，那他的愛可能只是說說而已，妳要相信自己的直覺，不要一直幫他找理由。
我已經跟他溝通過了，但他還是老樣子，我該繼續等嗎？
親愛的，溝通一次沒改善，可以給第二次機會，但如果講了三次他還是沒動作，妳就要認真設停損了。等待不是問題，問題是妳等的是「他改變」還是「他其實沒那麼在意」。妳可以給自己一個明確的期限，比如一個月，期間觀察他有沒有具體調整，如果還是零，妳就要練習把重心拉回自己身上，因為妳的青春跟眼淚都很珍貴，不要浪費在一個只會用嘴巴愛妳的人身上。
雙魚座女生是不是特別容易遇到這種說愛卻不行動的男生？
沒錯，因為雙魚女生太容易心軟、太會美化對方，而且很怕衝突，所以很容易吸引到那種「出一張嘴」的類型。他們會覺得妳很好哄、很好說話，久而久之就懶得用行動證明。妳要練習的是「把標準說清楚」，不要讓對方覺得妳的包容是理所當然。比如一開始就溫和但堅定地告訴他：「我重視行動勝過言語，如果你真的在乎我，我會希望你說到做到。」這樣可以過濾掉一些只想撿現成的人。
