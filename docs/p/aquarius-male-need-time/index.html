常見問題 Q&A

水瓶男冷靜期還會回訊息，這樣是正常嗎？
非常正常，而且這是好訊號。水瓶男要空間不代表他要斷聯，他如果還會回你訊息、丟貼圖、分享生活小事，代表他心裡還有你的位置，只是在用低濃度的方式維持連結。你要做的是順著他的節奏回，不要因為他回得短就追問，也不要已讀不回故意冷回去，保持輕鬆自然就好，這樣他會覺得跟你相處沒有壓力，冷靜期反而會縮短。
水瓶男主動說要冷靜，我是不是要先提分手比較有尊嚴？
先不要衝動，因為水瓶男說冷靜多半真的是在要空間，你搶先提分手他只會覺得你在情緒化，反而合理化他需要遠離你的決定。尊嚴不是靠先喊分手來的，而是你能不能在不安裡穩住自己。你可以設一個觀察期，期間好好過生活，等他自己回來，如果他真的不回來，你再優雅退場也不遲，這樣主動權其實在你手上。

建議你避開質問句，改用分享加邀請的句型。你可以說「這幾天我想了一下，我發現我那天講話有點急，我想聽聽你當時的感受」，先承認自己可以調整的部分，再邀請他講。水瓶男對這種平等對話的接受度很高，因為他討厭被檢討，但喜歡一起把事情想清楚。記得語氣放軟，重點是讓他知道你是來溝通的，不是來算帳的。
