十一月八號到二十二號是這波桃花能量最強的時候，尤其十一月中旬那幾天，你會明顯感覺到人際互動變熱絡，不管是新朋友或舊識都可能擦出火花。建議你提前把這段時間的空檔留下來，不要排滿工作，主動答應聚會邀約，而且要打扮一下再出門，因為這段期間你容易遇到「原本沒想過會來電」的對象，保持開放的心態最重要。

第四季適合跟曖昧對象一起旅行嗎？
