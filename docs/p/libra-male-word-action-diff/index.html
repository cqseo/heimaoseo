深度解析

親愛的，妳會來問這個問題，代表妳心裡其實已經有答案了，只是還想找個人幫妳確認一下對不對。天秤座男生說愛妳但行動不一致，這件事情真的不是妳想太多，也不是妳太敏感，而是他們天生就有一種「嘴巴比腳快」的傾向。天秤座由金星守護，他們非常懂得怎麼說出讓人心動的話，浪漫的詞彙、溫柔的語氣、剛剛好的承諾，這些對他們來說就像是呼吸一樣自然。但問題來了，天秤座的行動力往往跟不上他們的語言能力，因為他們內心有一個很深的矛盾，就是「想要討好所有人」以及「害怕做出錯誤決定」。當他說愛妳的時候，那個當下他可能是真心的，因為他確實感受到喜歡妳的情緒，但當需要付諸行動的時候，他會開始猶豫，會想說這樣做會不會影響到其他關係，會不會讓自己失去自由，會不會選錯了怎麼辦。所以妳會看到他嘴上說想見妳，但每次約會都要妳主動敲時間；他說會改掉已讀不回的習慣，但隔天還是一樣消失半天；他說妳很重要，但週末寧願跟朋友出去也不願意撥兩個小時給妳。這不是他不愛妳，而是天秤座的愛常常停留在「感覺層面」，還沒有被轉化成「行動層面」。他們很擅長經營一種氛圍，讓妳覺得被愛，但當妳需要具體的證明時，就會發現那些承諾像空氣一樣抓不住。更讓人生氣的是，天秤座男生通常不覺得自己有問題，他會覺得「我明明就說了啊」、「我心裡是這樣想的啊」，他沒有意識到對妳來說，沒有行動的愛就像沒有存檔的報告，看起來很漂亮但根本不能用。妳會陷入一種自我懷疑，想說是不是自己要求太多，是不是自己太咄咄逼人，但親愛的，妳要的是最基本的東西，就是言行一致，這不是無理取鬧。天秤座男生的心理動機其實很簡單，他們害怕衝突，害怕一旦行動了就必須承擔後果，所以他們選擇用說的來維持關係的和諧，用承諾來換取妳的開心，但真正要執行的時候，他們會退縮，因為執行動作意味著要面對可能的摩擦和壓力。這就是為什麼妳會覺得他好像愛妳，但又好像沒有那麼愛妳，因為他的愛是懸在半空中的，沒有落地。

具體建議

好，既然我們知道天秤座男生是怎麼回事了，接下來我要給妳幾個很具體的應對方式，讓妳不會再被他那些好聽話牽著走。第一個建議是「把感覺變成數字」，天秤座男生很會講感覺，但妳要把他拉回現實，比如他說很想妳，妳就回他「那這週末你有空嗎，我們星期六下午兩點見，你幾點可以到」，直接給出具體的時間和地點，讓他沒有模糊空間。如果他說再看看，妳就說「好，那我先安排自己的事情，你確定再跟我說」，然後真的去安排自己的行程，不要等他。第二個建議是「用選擇題取代是非題」，天秤座最怕做決定，所以妳不要問他「你要不要來」，而是問他「你星期六要來我家還是我們約在外面」，給他兩個選項，他會比較容易選一個，因為他不用面對「要不要」這個壓力，只要選哪個就好。第三個建議是「設定停損點並且說出來」，妳可以找一個氣氛好的時候跟他說「我發現我們之間有一個狀況，你說的跟做的常常對不上，這讓我很沒有安全感，我不是要逼你，但我需要知道你是不是真的想經營這段關係，如果是，我們一起來想辦法，如果不是，我也需要知道」，這段話的重點是溫和但堅定，把球丟給他，讓他正視這個問題。第四個建議是「用行為回應行為，不要用情緒回應話語」，當他說了什麼但沒做到，妳不要生氣也不要質問，就淡淡的說「好，我知道了」，然後把注意力放回自己身上，天秤座男生很怕失去平衡，當他發現妳不再因為他的話而開心的時候，他會開始緊張，這時候他才會真的去行動。第五個建議是「給他一個具體的任務」，比如跟他說「下週三晚上你訂一間餐廳，我們去吃，訂好跟我說哪間」，把主動權交給他，但任務要非常明確，有時間有動作，如果他連這個都做不到，那妳就知道他的愛有多少了。記住，對付天秤座男生不是要跟他吵，而是要讓他看到行動跟不行動的差別，當他發現不行動真的會失去妳的時候，他才會願意從那個舒服的觀望位置站起來。

常見問題 Q&A

天秤座男生是不是都只會說不會做？
不是全部都這樣，但很多天秤座男生的確有這個傾向，因為他們太在意平衡跟和諧，害怕行動會打破現狀，所以會用說話來維持關係的溫度，但實際上要看他有沒有意識到這個問題，如果有自覺並且願意調整，他還是可以變成行動派，關鍵是妳有沒有讓他明白口頭承諾對妳來說是不夠的。
我應該直接跟他攤牌說他言行不一嗎？
可以說，但要用對方式，不要用指責的語氣，比如說「你每次都這樣」會讓他防衛，妳可以改成「我發現我們之間有一個狀況，你說的跟做的有時候不太一樣，這讓我很困惑，我想聽聽你的想法」，用我開頭的句子表達感受，而不是用你開頭的句子指責他，這樣他比較不會急著解釋或逃避，也比較願意坐下來談。
要怎麼判斷他是真的愛我還是只是習慣說好聽話？
看他在不重要的事情上有沒有行動，比如他說記得妳喜歡喝什麼飲料，下一次見面他有沒有順手帶一杯，或者他說會早點回訊息，有沒有真的做到，這些小地方最能看出一個人有沒有把妳放在心上，因為天秤座男生如果真心在意一個人，他會在日常小事上展現出來，如果連小事都做不到，那他的愛大概只停留在嘴巴上。
