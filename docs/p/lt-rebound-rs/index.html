深度解析

先說結論，剛分手馬上交新戀情，不一定就是逃避，但很高機率你是在用「有人陪」來蓋住「我還沒好」的痛。很多台灣女生分手後最怕的不是失去那個人，而是晚上十一點滑手機沒人回、假日不知道要幹嘛、臉書回顧跳出兩個人吃火鍋的照片。於是當下出現一個對你很好、會接送、會說「你值得被疼」的人，你很難不心動。這不是花心，也不是隨便，這是一種很本能的心理止痛，就像腳扭到先貼貼布，但貼布底下骨頭有沒有歪，你根本還沒去照。命理上來看，剛斷掉的緣分氣場還很亂，這時候急著接新線，很容易把「舊傷的頻率」帶進新關係，你會不自覺拿新人跟舊人比，或是一直想證明自己有人要。真正要分辨是不是逃避，問自己三個問題：第一，我是喜歡這個人，還是喜歡「被喜歡」的感覺？第二，我一個人的時候，會不會還是想哭、還是會偷看前任？第三，如果這個新對象明天突然消失，我是難過失去他，還是難過又變回一個人？如果答案偏向後面，那這段新戀情比較像止痛藥，不是正餐。與其急著貼標籤說自己逃避，不如承認：我現在很脆弱，我需要陪，但我也要對自己誠實。

具體建議

如果你發現自己好像真的在逃避，別急著罵自己，先做這幾件事。第一，給自己七天觀察期，這七天不要急著定義關係，跟對方說：「我剛結束一段感情，我很喜歡跟你相處，但我想把腳步放慢一點，我們先好好認識彼此，可以嗎？」這句話不傷人，也幫你爭取空間。第二，拿一張紙，左邊寫「我懷念前任的什麼」，右邊寫「新對象讓我心動的什麼」，寫完之後看兩邊有沒有重疊，如果重疊的都是「有人陪、有人載、有人聽我說話」，那你要處理的是寂寞，不是新戀情。第三，設定一個「不聯絡前任」的三十天挑戰，把對話框隱藏、把照片收進資料夾，不是要你恨他，是要讓你的心有空檔。第四，找一個信任的朋友當你的「煞車皮」，跟對方說好，如果我在一個月內說要跟新對象同居或見家長，你就用力阻止我。第五，每天留二十分鐘給自己，不滑手機、不傳訊息，只問自己：「我今天好嗎？」剛分手的人最怕安靜，但安靜才是你聽見自己聲音的時候。記得，慢下來不是拒絕幸福，是讓幸福來的時候，你已經站穩了。

常見問題 Q&A

剛分手就有人追，我該答應嗎？
先問自己是被他吸引，還是被他的殷勤吸引。你可以答應出去喝咖啡、看電影，但先不要急著貼上男女朋友標籤。觀察他怎麼對待你的情緒，也觀察你自己一個人的時候穩不穩。如果每次約會完反而更空虛，那就代表你需要的不是新戀情，是先把舊的自己撿回來。
怎麼判斷新對象是不是備胎？
看你有沒有偷偷拿他跟舊愛比較，還有你會不會不敢讓朋友知道你們太快在一起。如果你講到前任還會紅眼眶，卻急著跟新人放閃，那新人很可能在幫你撐場面。真正適合的人會願意等你，不會因為你說想慢一點就跑掉，這點很好驗證。
分手後馬上在一起，會幸福嗎？
有可能，但機率不高，因為你帶著未處理的傷進去，很容易把舊問題複製到新關係。幸福不是不可能，重點是你有沒有在關係裡持續整理自己。如果你願意跟新對象坦白你還在復原，也願意給自己獨處的時間，那這段關係就有機會走得穩，而不是只是換一個人來陪你痛。
