常見問題 Q&A

求紅線一定要擲到聖筊才能拿嗎？如果一直擲不到怎麼辦？
對，一定要擲到聖筊，因為這代表月老同意賜線給你。如果一直擲不到，先不要急，可能是你剛剛講的條件太模糊，或者你心裡其實還沒準備好。你可以重新跟月老說一次，把條件講更清楚，或者先問月老是不是有話要跟你說，用擲筊方式一個一個問，有時候是月老在提醒你，目前先把重心放在自己身上，等一陣子再來求，紅線這種東西真的不能硬拿，硬拿反而會求到不適合的對象。
紅線要戴在哪裡？可以綁在手上還是放錢包？弄丟了怎麼辦？
紅線最常見就是放在錢包內層或隨身包包的小口袋，也有人會綁在手腕上，但建議不要綁太緊，以免斷掉。重點是你要讓它跟著你，象徵月老的能量一直陪伴你。如果紅線不小心弄丟或斷了，不用太緊張，不是什麼壞預兆，代表它幫你擋掉了一些不好的緣分，你只要找時間再回去行天宮跟月老稟報一下，重新求一條就可以了，月老不會因為這樣就生氣。
求完紅線之後，還有什麼事情要特別注意的嗎？
求完之後，最重要的就是保持開放的心態，多參加一些社交活動，不要整天待在家裡滑手機，緣分不會自己來敲門。另外，有人說紅線不要讓別人亂摸，這個說法見仁見智，但我會建議你收好就好，不用太刻意。還有一點，求完紅線之後的三個月內，盡量不要去做一些破壞感情運的事情，比如說跟人家曖昧不清、或者去參加一些奇怪的聯誼場合，保持自己的磁場乾淨，月老幫你牽線才會牽得順。
