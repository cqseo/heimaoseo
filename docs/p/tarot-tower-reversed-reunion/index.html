深度解析

抽到高塔逆位來問復合，說真的，你現在的心情我完全懂，因為這張牌擺明了就是「事情還沒炸完，只是暫時沒爆」。高塔正位的時候是瞬間崩塌、一翻兩瞪眼，可能一通電話就分手、一個晚上就搬家，痛歸痛但至少乾脆。可是逆位不一樣，逆位的高塔像什麼？像地震之後房子歪了、牆裂了，但還沒倒，你們兩個人就站在那棟危樓裡面，誰都不敢先走，也誰都不敢說「其實這裡已經不能住了」。你問我復合是好是壞，我會說：這不是好壞的問題，是「你有沒有看清楚這棟樓的結構已經壞在哪裡」。很多人抽到高塔逆位會誤以為是「災難解除、有轉圜餘地」，然後就急著復合，結果回去之後發現同一套劇本再演一次，只是這次撐得比較久、傷得比較深。逆位真正的訊息是：破壞的能量被延後了，但沒有消失。它可能變成冷戰、變成互相折磨、變成兩個人都在忍，表面上復合了，心裡卻一直在倒數計時。所以重點不是「能不能復合」，而是「你們願不願意先處理那個讓塔歪掉的地基問題」。如果你們當初分手是因為價值觀、金錢、家庭、信任這些結構性的東西，那逆位高塔就是在提醒你，這些問題不會因為一句「我們再試試看」就自動修好。但反過來說，逆位也代表「還有機會補救」，因為塔還沒全倒，你還有時間去做那些正位時來不及做的功課。這張牌其實很溫柔，它在跟你說：你可以不用急著現在就決定復合或不復合，先去看見那個裂縫，去承認它，然後再決定你要修它，還是要離開它。

具體建議

那具體要怎麼做？我給你幾個很實際的步驟，你照著走會比較穩。第一步，先做「危樓檢測」，拿一張紙，左邊寫你們分手前最常吵的三件事，右邊寫「這件事如果一輩子都不會改，我能不能接受」，寫完你就會很清楚這棟樓還能不能住，這一步不要偷懶，很多人復合失敗就是因為跳過這一步。第二步，設定「觀察期」而不是「復合期」，你可以跟前任說：「我不是要逼你現在給答案，但我想我們可以先把話講清楚，先當朋友聊一個月看看，不要急著回到以前的模式。」這句話的關鍵是「不要急」，因為高塔逆位最怕的就是急，一急就又會用舊模式相處。第三步，找一個「第三方翻譯蒟蒻」，也就是你們共同信任的朋友，但這個人不能是會選邊站的那種，你要請他幫忙在你們中間傳話或提醒，比如你情緒上來想傳長篇大論的時候，先傳給這個朋友看，請他幫你踩煞車。第四步，安排一次「低壓力的碰面」，不要選情人節、不要選紀念日、不要去你們以前約會的老地方，選一個中性一點的咖啡廳，聊三十分鐘就好，重點是觀察對方現在的狀態，而不是急著確認關係，你可以開場說：「今天沒有要談復合，只是想看看你最近過得怎樣。」這句話會讓對方卸下防備，你也比較能看清楚他是不是真的變了。第五步，給自己設一個「停損點」，比如兩個月，時間到了如果對方還是一直閃躲、一直說「再看看」，那你就要認真考慮是不是該讓這棟樓自然倒塌，因為高塔逆位最怕的就是你一直住在危樓裡，住到最後連自己都忘了外面還有別的房子可以住。

常見問題 Q&A

高塔逆位是不是代表復合有機會成功？
不能這樣直接解讀。逆位代表的是「破壞被延後」，不是「破壞消失」。它有機會成功，但前提是你們願意正面處理當初讓關係崩掉的那個核心問題，例如信任、金錢觀或家庭壓力。如果只是因為捨不得而復合，那通常撐不久，而且下一次爆炸會更痛。所以與其問會不會成功，不如問你們有沒有一起做過功課。
如果對方主動提復合，我該馬上答應嗎？
先不要。高塔逆位最怕衝動，你可以回他：「我也有在想這件事，但我不想我們又回到以前的樣子，可以給我一點時間，我們先聊清楚再決定嗎？」這樣講既沒有拒絕，也替自己爭取觀察空間。接著至少給自己兩週，看他是真的有反省，還是只是寂寞。急著答應通常會讓舊問題原封不動搬回來。
我怎麼判斷這段關係還值不值得修？
看三件事：第一，對方願不願意承認自己的部分，而不是把錯都推給你；第二，你們吵的那個點有沒有具體的改變方案，不是只有對不起；第三，你想到復合的時候，是期待還是害怕。如果想到的是「終於可以安心」，那可以試；如果想到的是「又要開始忍耐」，那這棟樓可能真的該拆了。誠實面對這三題，答案會很清楚。
