深度解析

抽到月老靈籤第70籤，我懂你現在心裡那種七上八下的感覺，因為這支籤其實很妙，它不是在給你一個「是」或「否」的痛快答案，而是在告訴你「這段緣分現在正走到一個需要重新校準的節點」。第70籤的籤意核心通常圍繞著「花開花謝有時，緣起緣滅有律」，它象徵的是一種等待與觀察的智慧，而不是衝動的斷捨離或死命的緊抓不放。你可能會覺得很煩，想說月老怎麼不乾脆一點，但其實祂是在提醒你，這段關係裡頭有一些東西還沒有被真正看清楚，可能是對方還沒準備好，也可能是你自己心裡還有一塊不確定。籤詩裡常出現的意象像是「雲開月出」或「柳暗花明」，這代表眼前的迷霧不是永久，但它需要時間散去，而這個時間長短，取決於你們兩個人願不願意把話講開、願不願意正視問題。從命理的角度來看，第70籤往往暗示這段緣分並不是「爛緣」，但它帶有考驗的性質，也就是說，它值得繼續，但前提是你要先搞清楚自己到底在堅持什麼。是習慣？是不甘心？還是真的看見了對方身上那個讓你願意再賭一把的特質？很多時候我們抽到這支籤，會一直問「他到底愛不愛我」，但籤意其實在反問你「你愛這樣狀態下的自己嗎」。如果你在這段關係裡越來越委屈、越來越常懷疑自己，那就算籤意說有轉機，你也要先把自己拉回來。反之，如果你們之間還有溝通的可能，對方也願意在你表達不舒服的時候調整，那這支籤就是在告訴你「再給彼此一個觀察期，但這個觀察期要有明確的停損點」。所以，這段緣分值不值得繼續，答案不在籤裡面，而是在你們下一次坐下來好好講話的時候，你有沒有勇氣把真正的需求說出來，然後看對方的反應來決定。

具體建議

好，既然都抽到第70籤了，我們就不要只停留在「想」的階段，我給你幾個具體可以做的事情，你照著做，大概一到兩個月內就會有很清楚的答案。第一件事，找一個雙方都放鬆的場合，不要用質問的語氣，你可以這樣開場：「我最近一直在想我們之間的相處，有些話放在心裡很久了，不是要吵架，只是希望我們可以更懂彼此，你願意聽我說一下嗎？」然後把你最在意的一到兩件事情講出來，比如「我需要你約會前先確認時間，不然我會覺得自己很像在等通知」或「你生氣的時候不講話，我會很慌，我們可以約好吵完架半小時內要傳個貼圖表示還在嗎」。講完之後，不要急著要他馬上回答，給他幾秒鐘，然後問：「那你聽到這些，你心裡的感覺是什麼？」這個問句比「你為什麼都做不到」有用一百倍。第二件事，給這段關係設一個為期六週的觀察期，在手機裡開一個備忘錄，每次你覺得委屈或開心的時候就記一筆，六週後回頭看，如果負面記錄遠遠多於正面，而且你已經講過兩次以上對方還是沒動作，那這就是一個很明確的訊號。第三件事，安排一次「不談關係」的約會，去看場電影、吃個小吃、逛個夜市都好，重點是觀察他在沒有壓力的時候怎麼對你，因為人在放鬆時的本能反應最真實。第四件事，找一個你信任、而且不會亂給建議的朋友，把你們的狀況講給他聽，請他當你的「現實檢查員」，當你又開始幫對方找藉口的時候，請他直接點醒你。最後，如果觀察期結束你還是很迷惘，那就再抽一次籤，但這次抽籤前先寫下「我已經試過哪些方法」，因為月老喜歡幫有在動的人，不是幫一直在原地繞圈的人。

  • 講需求時用「我需要」開頭，不要用「你為什麼都不」

常見問題 Q&A

抽到第70籤，是不是代表這段感情一定會復合或一定沒救？
都不是，第70籤比較像是「觀察期」的籤，它沒有把話說死。復合與否要看你們有沒有把之前分開的原因處理掉，如果只是因為寂寞又回頭，那籤意會提醒你同樣的坑會再跌一次。建議你先問自己「上次分開的那個問題，現在有答案了嗎」，如果沒有，先別急著復合，先當朋友觀察三個月，看對方有沒有實際改變，這比一直問籤更有用。
對方一直說會改但都沒動作，我還要繼續等嗎？
等到你設定的觀察期結束就好，不要無限延期。你可以很具體地跟他說「我希望看到你在某件事上有改變，比如約會遲到要先傳訊息，我們用一個月來看看」，一個月後如果完全沒動，那就是答案了。等待不是壞事，但沒有期限的等待會讓你越來越沒自信，你要把主導權拿回來，而不是讓對方決定你的青春要耗多久。
我已經很累了，但分手又怕後悔，該怎麼判斷？
你可以做一個「一個人的旅行練習」，挑一個週末自己去做一件本來你們會一起做的事，比如看展或吃火鍋，觀察自己一個人的時候是覺得鬆一口氣還是很想他。如果是鬆一口氣居多，那你的累可能已經大過愛了。另外，寫下「如果這是最後一次機會，我最想跟他一起完成什麼」，如果寫不出來，那這段緣分大概已經走到尾聲，不用硬撐。
