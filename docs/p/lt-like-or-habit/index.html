深度解析

其實這個問題會冒出來，通常代表你心裡已經有一點怪怪的感覺了，只是還不敢承認而已。很多台灣女生談感情談到一個階段，會突然卡住，明明他沒做錯什麼大事，也沒劈腿沒冷暴力，甚至對你還是很好，但你就是會在某個滑手機的深夜，或他睡著打呼的時候，盯著天花板想：「我到底是喜歡他，還是只是習慣他在？」先說，會問這個問題的人，通常不是不愛，而是愛已經從熱戀期的火花，變成日常生活的背景音了。習慣這件事本身沒有錯，感情走到後來本來就會有習慣的成分，問題在於你們的關係裡還有沒有「主動選擇」的成分。喜歡跟習慣最大的差別是：喜歡會讓你想靠近、想知道、想付出，習慣則是你不做也不會痛，但做了也不會特別開心。你可以回想一下，最近一次你主動想跟他分享一件小事是什麼時候？是興奮地傳訊息給他，還是只是因為不知道要傳給誰？還有，你們相處的時候，你是覺得放鬆、被理解，還是只是覺得「反正也沒別的事」？另一個很準的指標是「想像力測試」：如果明天他跟你說他要出差一個月，你第一個反應是鬆一口氣，還是心裡空一塊？鬆一口氣不代表不愛，但可能代表你們的相處模式已經讓你累了。還有一個更狠的：如果現在出現一個條件跟他差不多、但讓你心跳加速的人，你會不會動搖？會動搖不一定是渣，而是提醒你，你現在的感情裡缺少了某種讓你覺得「被點燃」的東西。習慣常常是愛情的保護色，它讓你不用面對改變，但也讓你不知不覺把「將就」當成「穩定」。所以與其急著貼標籤，不如先承認：你現在的感覺是真實的，值得被好好檢視，而不是用「應該要知足」四個字打發掉。

具體建議

好，既然你已經開始懷疑了，那就不要只靠感覺，我們來做幾件具體的事。第一招，寫「情緒帳本」，連續七天，每天睡前花三分鐘，寫下今天跟他互動中最有感覺的一件事，開心的、煩的、無感的都寫，七天後回頭看，如果開心的比例不到三成，那習慣的成分可能真的比較高。第二招，安排一次「沒有劇本的約會」，不要再去那家你們吃到膩的火鍋店，也不要只是在家看Netflix，挑一個你們都沒去過的地方，像是一起去逛建國花市，或報名一堂手作課，觀察他在陌生情境裡的反應，也觀察你自己會不會因為他的存在而覺得有趣。第三招，做「一週小別測試」，不用真的分手，就是刻意減少聯絡頻率，比如原本每天講電話，改成兩天講一次，看你的心情是輕鬆還是焦慮，如果他沒打來你反而覺得賺到，那答案就很明顯了。第四招，直接問自己一個狠問題：「如果現在單身，我會想追他嗎？」不要想他對你多好，就想他這個人本身，你想不想跟他約會、想不想了解他的生活。第五招，如果你們已經交往超過兩年，可以試著聊「未來藍圖」，用輕鬆的語氣問他：「欸，你有想過五年後我們會是什麼樣子嗎？」看他怎麼回答，也看你聽到答案時心裡是期待還是敷衍。這些動作不是要你馬上做決定，而是幫你把模糊的感覺變成看得見的線索。記得，習慣不是罪，但如果你發現自己只是習慣，那就要問自己：我願意繼續習慣下去嗎？如果不願意，那改變的第一步，就是先承認這件事。

  • 刻意安排一次沒去過的新地點約會，觀察彼此在陌生情境的反應。
  • 直接問自己：如果現在單身，我還會想追他嗎？答案會很誠實。

常見問題 Q&A

如果我們已經在一起很久，習慣他是不是就等於不愛了？
不一定喔，長期關係本來就會有習慣的成分，重點是習慣裡還有沒有「主動選擇」的意願。你可以問自己：如果今天重新選一次，你還會選他嗎？如果答案是會，那習慣只是愛情的日常版，不是問題。但如果答案是「好像也不會特別想」，那就要認真面對了。建議你觀察你們之間還有沒有新的共同目標或期待，沒有的話，可以試著一起規劃一件小事，重新點燃互動的動力。
我怕講出來會傷到他，該怎麼開口比較好？
千萬不要用「我覺得我好像只是習慣你」這種開場，太傷人了。你可以用「我最近在想我們的關係」當起頭，接著說「我很在意我們之間還有沒有那種一起前進的感覺，所以想跟你聊聊」，把焦點放在「我們」而不是「你」。如果氣氛允許，也可以提議一起做一件沒做過的事，用行動代替審問，會讓對方比較願意敞開心房，也比較不會覺得被否定。
要怎麼判斷他是真的喜歡我，還是也只是習慣？
觀察他對你的「主動性」和「細節記憶」。習慣你的人會在你生病時說多喝水，喜歡你的人會直接買藥過來；習慣你的人記得你生日，喜歡你的人記得你怕冷、記得你討厭香菜。還有一個指標：他會不會主動跟你分享他的生活小事，而且是那種沒什麼重點的瑣事，因為喜歡一個人會想讓對方參與自己的生活。你也可以偶爾丟一個小需求測試，看他回應的溫度和速度，但不要變成考驗，不然會反效果。
