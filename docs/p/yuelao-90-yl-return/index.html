深度解析

抽到月老靈籤第90籤，籤詩意境是「雲開月出正分明，不須進退問前程，婚姻皆由天註定，和合清吉萬事成」，這支籤其實是月老在告訴你，你們之間的感情不是斷了，而是暫時被雲遮住了。很多女孩來問我「分手後他會回來嗎」，我會先問她一句：你現在是想要他回來，還是想要一段真正適合你的感情回來？這兩件事聽起來很像，但其實差很多。第90籤的核心象徵是「雲開月出」，意思是現在這段關係正處於模糊、看不清的階段，雙方的情緒都還在下雨，但月亮本身沒有消失，只是被雲擋住。這支籤在感情裡最常對應到的狀況是：分手的原因不是不愛，而是時機不對、溝通卡住、某一方壓力太大或自尊心作祟。也就是說，他心裡不是沒有你，但現在的他還沒有準備好面對你們之間的問題。籤詩說「不須進退問前程」，白話一點就是叫你先不要急著往前衝、也不要急著往後退，現在最該做的是把重心放回自己身上。而「婚姻皆由天註定」不是叫你認命，是提醒你，真正屬於你的緣分，就算繞一圈也會回來，不屬於你的，你抓再緊也會走。所以這支籤對「他會不會回來」的答案是：有機會，但不是你現在苦苦等就會回來，而是當你們兩個人都把各自的雲撥開之後，月自然會亮。你要看懂的是，他回來的前提不是你想他，而是他願不願意面對當初讓你們分開的那個問題。如果那個問題沒解決，他回來了也只是再痛一次。所以第90籤其實是在溫柔地提醒你：先把眼淚擦乾，把日子過好，把自己照顧好，因為月老要給你的，不是一個逃走的他，而是一個準備好的他。

具體建議

接下來我給你幾個比較具體、可以馬上做的事，不要只放在心裡想。第一步，先給自己設一個「不聯絡觀察期」，至少三到四週，這段時間不要主動傳訊息、不要看他限動就忍不住回、也不要去問共同朋友他的近況，因為第90籤的雲要散，需要的是時間和空間，你一直去撥雲，雲只會更亂。第二步，把你們分手的那個「真正原因」寫下來，不是寫誰對誰錯，而是寫「什麼情況下我們會再吵同一件事」，比如他是不是一忙就消失、你是不是一沒安全感就逼問，寫清楚之後，你才會知道就算他回來，你們要面對的是什麼。第三步，如果你真的很想試探，觀察期滿之後可以用一句很低壓力的話開場，比如「最近好嗎？前陣子整理東西看到你之前留的東西，想說問一下要不要還你」，這句話不談感情、不逼表態，只是開一扇門，看他願不願意走進來，如果他很冷淡或已讀不回，那就是月老在幫你省時間。第四步，把「他回來」的判斷時機抓出來，通常第90籤對應的時機點會在農曆月圓前後、或是你們分手滿一個月到三個月之間，如果他主動聯絡你，而且願意講到當初的問題，那才是真的回來，如果他只是半夜傳一句「在幹嘛」，那不叫回來，那叫無聊。第五步，也是最重要的，不管你多希望他回來，你都要先讓自己過得好，去運動、去跟姊妹吃飯、去學一個新東西，因為當你整個人亮起來的時候，他回不回來，你都不會輸。

💡 實用小提醒

  • 先設三到四週不主動聯絡的觀察期，把通知關掉。
  • 寫下你們真正吵架的原因，不是寫對錯，是寫模式。
  • 想試探就用還東西這種低壓力理由開場，只發一次。

常見問題 Q&A

他分手後都沒封鎖我，是不是還有機會？
沒封鎖不等於還想復合，很多人只是懶得處理或不想撕破臉。你要看的是他有沒有主動、有沒有關心你的生活，而不是只看封鎖與否。如果他只是留著聯絡方式卻完全不互動，那對你來說其實更耗，因為你會一直盯著那個對話框等。建議你先把通知關掉，觀察他有沒有在一個月內主動找你講到有意義的事，沒有的話，你就知道這個機會目前是空的。
我主動密他會不會讓他覺得我很廉價？
不會，但你要看密他的內容和時機。如果是分手後馬上狂傳、求他回來，那確實會讓對方有壓力。但如果是觀察期過後，用一個輕鬆、不帶目的的理由開場，比如問東西、問共同朋友的事，那就只是正常互動。重點是你要有「他回也好、不回也好」的底氣，你越不卑微，他越會重新看待你。記得一次就好，不要連發。
月老籤說有機會，那我是不是什麼都不用做？
不是什麼都不做，是不要亂做。第90籤的意思是時機還沒到，你現在硬衝只會把雲攪得更亂。你要做的是把自己整理好、把問題想清楚、把生活過回來，同時保持一個開放的狀態。等時機到了，他主動，你接得住；他沒主動，你也不會垮。真正的順其自然是盡力之後不強求，不是兩手一攤什麼都不管，這兩件事差很多。
