深度解析

常見問題 Q&A

他說需要時間，我到底要不要主動聯絡他？
可以聯絡，但要選對方式和頻率。建議用文字，三天一次為限，內容不要問「你想好了沒」，而是分享一件小事或一句關心，例如「今天經過那家你喜歡的店，想到你」。處女座需要感覺到你在，但不是被監視。如果他已讀不回，也不要連發，給他空間，他整理好會自己回來。
需要時間是不是代表他想分手？
不一定，而且多數時候不是。處女座說需要時間，通常是在做關係的品質評估，他要想清楚下次怎麼避免同樣的衝突。真正想分手的處女座會很直接，不會給你模糊的等待。你可以觀察他有沒有保留聯絡管道、有沒有偷偷看你的動態，這些都是他還在意的訊號。
等他回來之後，我該怎麼開口談？
先別急著翻舊帳。你可以說：「謝謝你願意花時間想這件事，我也想聽聽你的結論，我們一起看看怎麼調整。」把重點放在「一起調整」而不是「誰對誰錯」。處女座喜歡有架構的對話，你可以先講自己的反省，再問他的想法，他會覺得你有誠意也有邏輯，溝通就會順很多。
