常見問題 Q&A

不一定，水瓶女回訊息快通常只是因為她當下有空、話題有趣，或是她覺得跟你聊天很輕鬆。真正要看的不是速度，而是她會不會主動開話題、會不會記得你講過的小事、會不會在你面前講一些只跟少數人說的怪想法。如果她只是回得快但從來不主動，那你比較可能是在她的「聊得來朋友」名單裡，而不是喜歡名單裡。
