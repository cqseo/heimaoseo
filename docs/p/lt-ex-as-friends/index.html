深度解析

其實你會問這個問題，心裡大概已經有一個放不下的點了，對吧。和前任保持朋友關係這件事情，說真的沒有標準答案，但有一個很關鍵的判斷標準：這段友誼到底是讓你往前走，還是把你拉回原地。很多人在分手後會急著想證明自己很大方、很成熟，覺得當朋友好像就代表這段感情結束得很體面，可是親愛的，體面是給外人看的，你心裡的感受才是真的。你要先分清楚自己現在是「真的放下了，只想要一個淡淡的朋友關係」，還是「其實還沒放下，想用朋友的身分繼續留在他身邊」。這兩種狀況看起來很像，但本質天差地遠。如果是前者，那當朋友當然可以，你們可以偶爾聊聊近況、互相按個讚，不會因為他交了新對象就心裡酸酸的；但如果是後者，那這個朋友關係就會變成一種慢性折磨，你會因為他回訊息的速度忽快忽慢而心情起伏，會因為他提到哪個女生而整晚睡不著，表面上說是朋友，實際上你還在等他回頭。另外也要看你們當初是怎麼分手的，如果是因為價值觀不合、遠距離這種理性的原因分開，當朋友的難度比較低；但如果是被劈腿、被冷暴力、被突然消失，那這個朋友關係裡面藏著太多未處理的情緒，硬要當朋友只會讓你一直處在委屈的位置。還有一個很現實的點是，你要問自己「這個朋友關係對我的生活有什麼加分」，如果他只是偶爾出現、偶爾消失，讓你一直處在一種不確定的狀態，那其實你不是在經營友誼，你是在延長分手的痛苦。真正健康的友誼是雙向的、輕鬆的、不需要你小心翼翼的。所以與其問「這樣做正不正確」，不如問「這樣做讓我變成什麼樣的人」，如果你在這段友誼裡越來越焦慮、越來越沒自信，那答案其實已經很明顯了。

具體建議

好，如果你已經決定要試著當朋友，或者想確認自己到底適不適合，這裡給你幾個很具體的做法。第一步是先設一個「觀察期」，比如說三個月，在這三個月裡面你只做最低限度的互動，不要主動私訊、不要單獨約見面，就只是讓彼此存在在各自的生活裡，然後你記錄一下每次互動完你的心情是輕鬆的還是沉重的，三個月後回頭看，如果大部分時候你都是平靜的，那可以慢慢增加互動；如果每次聊完你都要難過一整天，那就代表這個朋友關係對你是消耗的，你要勇敢踩煞車。第二步是設定清楚的界線，而且要用講得出來的話術，比如你可以跟他說「我們現在就是朋友，所以我不會再像以前那樣隨時回你，如果我有空再聊」，這句話很溫和但很清楚，把期待值拉回朋友該有的位置。第三步是不要什麼都跟他說，尤其是你的感情動態、你的寂寞、你最近過得好不好，這些話留給真正在你身邊的朋友聽，因為前任不是你的情緒垃圾桶，你越依賴他，你就越難真正獨立。第四步是給自己一個「不聯絡的緩衝」，如果某一次聊天讓你情緒很亂，你可以直接說「我最近比較忙，先這樣喔」，然後真的把對話放下，不需要解釋太多，這是在保護你自己。第五步也很重要，就是去建立新的生活重心，不管是運動、上課、認識新朋友，當你的生活夠豐富的時候，你就不會把前任的訊息當成你情緒的開關。最後想提醒你，當朋友不是一種義務，你不當朋友也不會顯得你小心眼，選擇讓自己舒服的方式，才是真正成熟的表現。

常見問題 Q&A

分手後多久當朋友比較合適？
建議至少間隔三到六個月，而且要真的經歷過一段完全斷聯的時期。剛分手的時候情緒還在震盪，這時候當朋友很容易變成藕斷絲連，你會分不清自己是寂寞還是真的想當朋友。等到你可以聽到他的消息心裡沒什麼波動，甚至能真心祝他幸福，那時候再當朋友品質才會好，也才不會互相消耗。
如果現任介意我和前任當朋友怎麼辦？
這題要先尊重現任的感受，因為安全感是感情的基礎。你可以先問清楚他介意的點是什麼，是怕你們舊情復燃，還是怕你拿他來比較，然後針對那個點去調整，比如減少單獨見面、不在深夜聊天、不聊感情私事。如果現任是完全不能接受任何聯絡，那你也要評估這段友誼對你有多重要，有時候取捨是必要的，但不要用欺騙的方式處理。
怎麼判斷自己是不是還愛著前任？
最簡單的測試是看你的情緒開關在誰手上。如果他一則訊息就能讓你開心一整天，他一句冷淡就讓你整晚睡不著，那你不是把他當朋友，你是在等他回頭。真正放下的人，聽到他交新對象會有點感慨但不會心痛，聊天頻率變少也不會焦慮，你可以用這個標準誠實地問自己，答案通常很清楚。
