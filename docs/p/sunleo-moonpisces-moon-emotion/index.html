深度解析

具體建議

接下來給你幾個很具體的做法，你直接照著做就會有差。第一，建立「情緒翻譯機」的習慣：每次你覺得心裡怪怪的，先不要急著演小劇場，拿手機備忘錄寫下三行，第一行寫「我現在的感覺是⋯⋯」，第二行寫「我猜對方可能⋯⋯」，第三行寫「我真正想要的是⋯⋯」。例如你寫「我現在的感覺是失落，因為他回訊息很慢；我猜他可能在忙；我真正想要的是他跟我說一聲他在忙」。寫完之後，你就用這個句型跟他說：「寶貝，我知道你可能在忙，但我剛剛有點小失落，因為我很期待跟你聊天，下次如果會晚回，可以先跟我說一聲嗎，我會很安心。」這句話超好用，因為它同時滿足了獅子被尊重的需求跟雙魚被安撫的需求。第二，設一個「討好停損點」：每次你想為對方多做什麼之前，先問自己「這件事我是心甘情願，還是怕他不高興？」如果是後者，就先停三秒，改成說「我這次可能沒辦法幫你耶，但我可以陪你一起想辦法。」你要練習讓對方知道你的界線不是不愛，而是你也要照顧自己。第三，每週安排一次「獅子充電時間」：去做一件讓你覺得自己很棒的事，可能是打扮漂亮去喝咖啡、運動、學新東西，因為你的安全感不能全部放在感情裡，你要讓自己有自己的舞台，這樣你才不會一直盯著對方有沒有給你足夠的關注。第四，練習「直接要」：雙魚月亮很會給，但不太會要，你可以從小事開始，例如「我今天想要你抱我一下」、「我現在需要你聽我講五分鐘，不用給建議」。你會發現，當你講得越清楚，對方越知道怎麼愛你，你也不用再靠猜心來談戀愛。第五，吵架的時候設「暫停暗號」：因為你情緒一上來會先縮或先哭，獅子又會硬撐，你們可以約定一個暗號，比如說「我需要喝口水」，一講出來就代表先暫停十分鐘，各自冷靜，回來再講，這樣可以避免你在情緒最高點說出傷人的話，也可以避免你委屈到直接提分手。

常見問題 Q&A

月亮雙魚是不是很容易在感情裡委屈自己？

太陽獅子月亮雙魚的人適合什麼樣的伴侶？
