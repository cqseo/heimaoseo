深度解析

常見問題 Q&A

真的會，而且影響比你想的大。上升星座管的是你怎麼「出場」，包含講話節奏、表情、穿著風格跟面對陌生人的防備程度，這些都是別人三秒內會收到的訊號。你可以把它想成你的預設桌布，別人先看到那張圖才開始認識你。所以與其說參考，不如說它是你感情裡的門口守衛，守衛的態度決定誰願意走進來。

用「分段揭露」的方式最自然。第一次約會先讓上升的你出場，輕鬆聊天就好；第二次約會開始放一點太陽摩羯的原則，比如講你對工作的想法或你在意的事；第三次再讓月亮巨蟹出來，分享一點私人的情緒或童年小事。不要一次全倒，也不要全部藏起來，像剝洋蔥一樣一層一層來，對方會覺得你很有深度，而不是很複雜。
