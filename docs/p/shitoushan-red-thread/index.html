常見問題 Q&A

求完紅線後如果一直沒消息，是不是要再去求一次？
不用急著再求，先回頭檢查你當初講的條件是不是太嚴或太模糊，很多人求完就忘記自己講過什麼。建議三個月後再回山上跟月老聊聊，把條件微調，順便看看是不是自己生活圈太小，與其一直求線，不如先擴大同溫層，參加一些有興趣的課程或社團，讓緣分有機會發生。
紅線可以跟朋友一起去求嗎？兩個人一起求會不會互相影響？
可以一起去，但求的時候要分開擲筊、分開稟報，不要兩個人在同一尊月老前擠在一起講，這樣磁場會亂。另外，千萬不要幫朋友代求，也不要拿朋友的紅線來過爐，每個人的緣分是獨立的，你幫他求等於把兩個人的感情路綁在一起，反而容易出問題，各自求各自的卡實在。
求到的紅線如果斷掉或不小心弄丟怎麼辦？
先不要緊張，紅線斷掉不代表緣分斷，有時候是它幫你擋掉一段不好的緣分。如果斷了，用紅包袋裝起來收好，下次回獅頭山時帶去化掉，再重新求一條就好。但如果是不小心弄丟，心裡會毛毛的話，可以打電話去勸化堂問問看能不能補求，重點是心態要穩，不要自己嚇自己。
