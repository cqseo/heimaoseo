深度解析

屏東東港東隆宮的主祀神祇是溫府千歲，在地人都叫祂「王爺公」，每年迎王祭典是全東港的大事，但你知道嗎，其實東隆宮平日裡也是很多考生會特地跑去祈求考運的地方。我懂你現在的心情，那種準考證印出來、考試日期倒數計時、書唸不完又怕考場失常的焦慮，真的很像心裡有一顆石頭壓著。很多人以為求考試順利就是拿准考證去拜一拜、過個香爐就好，但其實東隆宮的祈願流程有它的講究，從拜拜的順序、供品的選擇、到怎麼跟王爺公稟報，每一個小細節都代表你的誠意。東隆宮是王爺廟，王爺公的個性比較威嚴、講義氣，也重視「你有沒有認真」，所以求考運的時候不能只說「讓我考上」，而是要講清楚你報考什麼、準備到什麼程度、希望王爺公幫你穩住哪個環節，這樣祂才知道怎麼幫你。另外，東隆宮的香火很旺，廟裡氣場比較強，很多考生會覺得進去之後心情比較安定，這其實就是一種心理上的定心作用，當你心定了，作答的時候比較不會慌，選擇題也不會手抖畫錯卡。還有一個重點，東港這邊的民間習俗會準備「蔥、蒜、芹菜、蘿蔔」這類有諧音的供品，蔥代表聰明、蒜代表算數精密、芹菜代表勤勞、蘿蔔代表好彩頭，這些都是老一輩傳下來的智慧。你要記得，求考運不是求神明幫你作弊，而是求一個心穩、運順、臨場不失常，所以流程走對，你的心也會跟著踏實起來。

具體建議

好，接下來我跟你說具體怎麼做，你照著這個順序走，第一次去也不會手忙腳亂。第一步，出發前先準備供品，你可以買一份水果（蘋果代表平安、香蕉代表招好運，記得不要用蓮霧，老一輩說會「霧煞煞」）、一份糕餅甜食（王爺公喜歡甜）、以及蔥蒜芹菜蘿蔔各一小把，用紅紙稍微綁一下，另外准考證影本一張、考生本人常穿的衣服一件。第二步，進廟後先到天公爐拜天公，稟報你的姓名、農曆生日、住址、報考類別與考場地點，請天公做主，再進主殿向溫府千歲行三拜禮。第三步，點香後跪在拜墊上，口訣這樣說：「弟子（信女）某某某，出生年月日，住在哪裡，這次報考什麼考試，考試日期是幾月幾號，考場在哪裡，弟子已經認真準備，懇請王爺公保佑弟子考試當天頭腦清楚、作答順利、臨場不緊張、畫卡不劃錯，若有疏漏還請王爺公指點。」講完後把准考證影本跟衣服拿在香爐上順時針繞三圈，這叫「過爐」，代表把王爺公的靈氣帶在身上。第四步，把准考證影本壓在供桌上，衣服帶回家考試當天穿，供品拜完留給廟方或帶回家吃平安。第五步，離開前到廟的右側金爐燒金紙，燒的時候心裡默念「感謝王爺公」。注意事項有幾個：月經來的女生傳統上不拿香、不碰供桌，可以在廟外雙手合十稟報就好；拜拜當天不要穿拖鞋、不要吃檳榔；準考證影本不要亂丟，考完再化掉或收好。最後一個小提醒，拜完之後不要一直回頭看，代表你已經把事情交給王爺公了，剩下就是好好唸書。

常見問題 Q&A

東隆宮求考運要準備什麼供品？有沒有禁忌？
基本供品是水果、糕餅、蔥蒜芹菜蘿蔔，水果以蘋果、香蕉、鳳梨為主，代表平安、招好運、旺來。禁忌部分，蓮霧諧音「霧煞煞」盡量避免，芭樂因為籽多不好消化也少用。另外供品數量以單數為佳，三樣或五樣都可以，拜完的供品可以帶回家吃平安，不要浪費。準考證影本記得帶一份，正本自己收好不要壓在廟裡。
拜完東隆宮之後，考試當天還要做什麼才能延續保佑？
考試當天早上出門前，先把過爐過的衣服穿上，心裡默念王爺公聖號三次，出門前不要罵人、不要跟家人吵架。進考場前深呼吸三次，把準考證放在桌面左上角，作答前先閉眼三秒鐘穩定心情。考完一科就不要對答案，避免影響下一科心情。另外可以帶一個廟裡求的平安符放鉛筆盒，但不要拿出來放在桌上，低調放著就好。
如果考試當天還是很緊張、失常了怎麼辦？
先別自責，緊張是正常的，王爺公保佑的是讓你穩住，不是讓你變神仙。當天如果手抖，就先放下筆、深呼吸、喝一口水，把題目重新看一遍，先做有把握的題目。考完之後可以回東隆宮向王爺公稟報感謝，順便說一下哪裡不順，請祂指點下一次。記得，一次考試不代表全部，王爺公看的是你的態度和努力，調整好心情再拼下一場比較重要。
